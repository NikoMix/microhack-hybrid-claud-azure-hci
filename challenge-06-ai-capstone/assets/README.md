# Capstone output folder

This folder is the **working output area** for the AI capstone (challenge 06). It starts
mostly empty on purpose — your **GitHub Copilot custom agents** write here at runtime.

## What lands here

| Artifact | Produced by | Module B |
|---|---|---|
| `arc-onboarding-runbook.md` | *Arc Onboarding Copilot* + `runbook-generator` skill | B.4.2 |
| `evidence-scorecard.md` | *Module B Audit Agent* + `evidence-validator` skill | B.4.1 |
| `current-state-architecture.md` | *Hybrid Cloud Architect* (Azure MCP) | B.1.1 |

> [!NOTE]
> Agent-generated files are **not** committed by default — they are per-pupil lab output.
> If you want to keep an example for your own Train-the-Trainer notes, copy it out of the
> Codespace before teardown.

> [!TIP]
> Treat everything here as **draft**. The human (you) reviews and edits before anything goes
> into the real Module B evidence package in
> [`../../challenge-05-specialization-readiness/`](../../challenge-05-specialization-readiness/).
